// flagship project

FINAL YEAR PROJECT · COMPUTER FORENSICS

ForensicEye — AI-Driven Digital Forensics Platform

A desktop forensics platform that pairs traditional DFIR tooling with an LLM + RAG layer, so an investigator can ask evidence questions in plain language and get answers grounded in the actual case data — not a hallucinated guess. Covers ingestion, artifact extraction, attack-chain reconstruction, and court-ready reporting, built to align with ISO/IEC 27037, NIST SP 800-86, and ACPO guidelines.

Python 3.11 Llama 3.1 LlamaIndex (RAG) Autopsy + Sleuth Kit Volatility3 YARA-X Neo4j Qdrant PyQt6
Learned: how to architect a full forensic pipeline from evidence ingestion to AI-assisted analysis, and why RAG is non-negotiable in a legal-grade AI tool.
